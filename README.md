

Built an end-to-end PDF Data Extraction workflow using n8n Cloud that:

📧 Monitors Gmail for incoming PDF emails
📄 Automatically extracts text from PDF attachments
🤖 Uses Google Gemini AI to parse structured data
📊 Logs all records into Google Sheets automatically

Tech Stack:
- n8n Cloud (workflow automation)
- Gmail API
- Google Gemini AI
- Google Sheets

This workflow eliminates manual data entry completely — the moment a client sends a PDF, the data is extracted and recorded within seconds.
